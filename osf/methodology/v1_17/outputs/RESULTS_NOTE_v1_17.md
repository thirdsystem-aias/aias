# v1.17 results note: how many runs are enough (exploratory)

Run once on Nov 12, 2026 (08:52 UTC), after the lock (tag `v1.17-prereg-r1`). Exploratory: no verdicts. Inputs: v0.42's t4 recall answers (N3, search off and on, three runs, 672 brand × model × condition units) and v0.41's three omnibus waves. Loader check: the published 49 brands below the recall floor (N3, search off) reproduced exactly.

**In short.** On the newest models, a brand's per-model Presence moves little from run to run: the standard error of one run is 0.069 (n = 672 units), so one run is already below 0.10 and two runs are below 0.05, assuming independent runs with the same variance as t4's three. The figure is much the same for the 16-brand and 24-brand categories. It is pulled down by the 416 of 672 units that did not move at all (224 never named, 15 named in every answer, the rest stable): for brands named in some answers but not all (n = 433), one run's standard error is 0.086 and below 0.05 needs 3 runs (4 in the 24-brand categories). Without Denon and the five brands with agency ties (S-COI), one figure changes: in the 16-brand category, below 0.05 needs 3 runs instead of 2 (within the primary interval of 2–3). All three runs were collected on one day, so day-to-day change is not in these figures.
