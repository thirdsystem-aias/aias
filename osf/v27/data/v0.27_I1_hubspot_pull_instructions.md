**Output sheet:** `osf/v27/data/v0.27_I1_hubspot_entry_TEMPLATE.csv` (24 brand rows prefilled, fields blank)
**Locked under:** v0.27-prereg-r3
**Frame (r3 `construct_alignment_rule`):** record the **category-competitive** field (Share of Voice). The free Grader runs its **own** prompt set — you cannot scope the category in the free tier — so SoV comes back tool-default-framed, NOT R_cat-aligned. Record it as-is; do not manually re-scope. This tool-default frame is exactly why I1's `construct_match` is pre-registered as **loose**.

---

## The convergent variable

`I1_sov` (Share of Voice) is the **only** field that feeds the convergent correlation (H_CV3_Primary: AIAS `recall_channel_som` × I1 SoV). SoV is the category-competitive measure — % of relevant AI responses mentioning the brand vs competitors — the closest analog to AIAS category-recall.

The `/100` composite is sentiment-dominated and brand-absolute. Record it as `I1_composite_100` for traceability, but it is **not** the convergent variable. The other four dimensions are recorded for the H_CV3_Component within-study MTMM block, not the primary.

## Procedure (one sitting, all 24)

1. Pull **all 24 brands in a single session** so the measurement is temporally consistent and lands inside the ±7d mutual window with I2/I3. Log the date/time in `pull_timestamp` (ISO, e.g. `2026-05-29T14:30`); a single session timestamp repeated across rows is fine.
2. For each brand: enter the **brand_name exactly as in the sheet**, run the grader, then record from the report:
   - `I1_sov` — the Share of Voice value. If the report shows a raw **percentage**, record the number and set `I1_sov_form = percent`. If it only shows the weighted **0–10 sub-score**, record that and set `I1_sov_form = subscore_0_10`. Be consistent across all 24.
   - `I1_sentiment` — the sentiment value (the −100..+100 scale if shown; otherwise the /40 sub-score — note which in `I1_notes`).
   - `I1_presence_quality`, `I1_brand_recognition`, `I1_market_competition` — the displayed values.
   - `I1_composite_100` — the overall score.
3. Leave `brand_id` / `brand_name` / `I1_engines` as prefilled.

## Blinding (important)

The sheet deliberately omits all AIAS-side values (recall_channel_som, R_cat/R_cult, cell, type-2 status). **Enter HubSpot numbers without consulting the AIAS scores** — the cell/type-2/AIAS join happens later at scoring, against the registry + `v0.27_aias_side.csv`. This keeps the pull from being anchored to known AIAS values. Don't add AIAS columns to this sheet.

## Nulls — do not invent

Some brands will return little or no assessment — the five defunct/absorbed Cell_D products especially (the grader may report minimal AI presence or decline to score). When that happens: set `null_flag = TRUE`, record whatever partial values appear (or leave blank), and note it in `I1_notes`. **Never fill a plausible-looking number.** Null brands route through the coverage gate (`min_n_for_valid_rho = 12`) at scoring; the panel is locked, so brands are never dropped from the registry — they just don't contribute to a correlation they have no data for.
